# Camera Atlas — 免费版 v2.2

价格：Free（免费）。Skill 版本：2.2.0；Python 引擎版本号为 0.1.0，通过固定源码版本和实际能力检查识别新版。

给能执行操作的 AI Agent 一张旅行照片和拍摄地点。Camera Atlas 引导它准备本地环境、查找真实地图、选择适合的整片天空或水面，并交付成品、透明地图和来源报告。保留原图方向、构图和支持的色彩光影；地图采用独立图层合成，不重绘整张照片，也不添加不透明方块卡片。

区域更宽或更长时，按统一比例扩展真实地理范围，并保护建筑、人物和重要树枝。Agent 检查区域边缘、地点标记和来源文字。精确机位 GPS 不是必填项；只提供地名时使用区域标记，不伪造机位。

实际制图在买家电脑上运行，需要：

- Python 3.11 或更高版本，文件读写和命令执行能力。
- 首次创建独立环境、安装经过校验的渲染器及依赖的权限。
- 初次下载和线上地图查询所需网络，或已经取得的可信离线数据。
- 图片理解和实际成品检查能力。

附中英双语新手说明，命令、查地图和选区由 Agent 完成。首次需要准备环境；普通聊天窗口仅能上传图片并不代表能制图。缺少执行能力时明确提供方案，不能声称已生成照片。

不要求付费 Agensi 生图工具、Camera Atlas 云账户或地名 API Key。用户现有 AI 订阅/API、电脑和网络可能另有费用。

限制：本地图片不超过 18 MB、2500 万像素，HEIC 需要可选解码器；使用 8 位 SDR 合成。无法保真的 HDR、高位深或色彩配置需要认可后的导出。选区建议需复核；截图清洗是单独步骤，不能恢复被遮挡的真实细节。等高线需要真实 DEM。不保证公共数据始终可用、所有照片或所有 Agent 通用兼容；真实 Trae 及普通 DeepSeek 网页/App 会话尚未验证。
