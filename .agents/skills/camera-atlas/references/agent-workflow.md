# User-owned agent workflow

Use this workflow after installing the verified renderer, whether the instructions came from Agensi, a native Skill import or the source-bundled Agent Kit. No hosted HTTP service, public tunnel, paid image API or Camera Atlas account is required. The source kit includes Python and public photos; the Agensi ZIP contains skill text and references. An import of instructions alone does not install Python dependencies.

## Capabilities and first setup

Check that the host agent can read the supplied photo, run Python 3.11+, write outputs and inspect images. A model's image input or tool-calling support alone is not an execution environment. DeepSeek used inside a capable local client may work; a plain chat interface must not be advertised as verified. Native Trae Skill import also does not prove Agensi remote OAuth compatibility.

For Agensi or a standalone Skill, use [onboarding.md](onboarding.md) and the fetched immutable lock. A lock declaring `agent_bridge`, `region_fill` and `online_maps` installs `maps` by default. If those declarations are absent, it is not the current online workflow; obtain the verified v2.2 package or use a trusted source kit rather than silently substituting a corner map.

For the source kit, locate its actual root (`pyproject.toml` and `src/camera_atlas/agent.py`). Create a new isolated environment there or in a user-approved working directory, or reuse a verified existing one. Install the source with its `maps` extra using that environment's Python (`python -m pip install '/actual/kit/root[maps]'`). Do not start the web server or install the optional `service` extra for this route. First setup can download Python packages. Record the actual interpreter path; do not assume `python` points to the new environment. On Windows the venv interpreter is under `Scripts`, not `bin`.

Use `onboard.py doctor --python /actual/venv/python --workspace /actual/task` for a read-only check. The online route requires `online_ready`, including the agent bridge, region-fill renderer and vector decoder. `offline_ready` alone is insufficient. Do not replace a verified current environment with a different locked revision. For offline installation, local compatible dependency wheels are still required; source does not include all dependencies. Inspect the supplied file format; install the optional `heic` extra in this same environment when needed, rather than rejecting a normal phone original or silently converting/resizing it.

## Prepare, resolve, render

These are operations for the agent to execute, not commands to give a novice as homework. Use absolute paths and one private task workspace throughout; do not place user photos inside a public repository.

1. Inspect the original photo. If the user requests screenshot UI/text removal, create and review a repair mask first and use the accepted clean base. The bridge does not perform generative cleanup. All revisions reuse that base.
2. Run `python -m camera_atlas.agent prepare --input /actual/clean-photo.png --workspace /actual/task`. Read its JSON; inspect the actual base and suggested region. The suggestion is a conservative color/texture heuristic, not semantic segmentation. It may be empty or imperfect. Use the host's image understanding to refine the full requested negative space and protect subjects. Keep the original orientation and exact normalized mask size. Do not ask the user to paint a mask if the agent can do this reliably itself; ask one focused question if uncertain.
3. Run `python -m camera_atlas.agent search --place 'Provided place and region' --workspace /actual/task`. The search uses Photon with shared local caching and a rate limit. Select only a returned server-issued ID. If multiple places match the user's description, ask for the relevant clarification. The ID identifies a locality, not camera GPS. `san-francisco` and `lucerne` are built-in offline sample IDs; never reuse them for other places.
4. After inspecting and approving/refining the region, run `python -m camera_atlas.agent render --photo-id RETURNED_ID --place-id VERIFIED_CANDIDATE_ID --region /actual/reviewed-mask.png --reviewed-region --workspace /actual/task`. Only use the review flag after actually reviewing the region. Choose a suitable `--map-mode` from the photo and place: urban street context should remain visible even when the city contains a pond or moat. Use `--radius-km` to set half the shorter geographic span when the default is too narrow or sparse. These are agent decisions, not additional fields the novice must supply. The bridge expands true geographic extent to match the mask and fetches bounded OpenFreeMap vectors; it does not stretch a square map. An offline sample extract cannot grow new coverage. Oversized extents, unsupported terrain contours, missing data and invalid geometry must be explained, not replaced with invented filler.
5. Inspect the returned final, mask, transparent layer and provenance. Check the entire selected region, subject holes, real-data extent and source attribution. The main place should be identifiable: if the source name cannot be rendered in the requested language, verify a concise display name and pass `--location-label`; this changes text only, never coordinates or location accuracy. Keep incidental labels small and subordinate. Check that credit is readable, complete and not duplicated or clipped. A successful exit means files exist, not that automatic aesthetics passed. Refine and rerender from the clean base when needed. Stop when files pass checks or a concrete unavailable capability/data source prevents further work; do not loop indefinitely.
6. Return actual absolute file links or attachments: final first, transparent map second, provenance third. Give one short limitation only if material. Never tell the user to retrieve a file from a server that was not created.

For a no-network demonstration, use a bundled public sample photo with its matching built-in place ID; no search step is needed. Explain that NASA aerial images are engineering samples, not travel-photo aesthetic benchmarks.

## Costs and privacy

The local bridge accepts up to 18 MB and 25 megapixels without resizing. Its compositor is 8-bit SDR; detected high-bit-depth/HDR HEIC must not be silently tone-mapped. Explain that limit and request an approved SDR export or permission for a separate conversion; retain the original. Do not describe a converted export as pixel-identical to an HDR source.

Camera Atlas adds no mandatory hosting or per-image generative API fee. The user's AI subscription/API usage, device and network costs still apply. Original images are processed in the authorized agent environment; an agent's cloud model may receive image context according to its own settings. Map providers receive location/range queries, not the photo. If China-region network access to GitHub/package indexes/Photon/OpenFreeMap fails, report the failed dependency or use supplied verified offline data. Do not promise cross-border availability or switch to unverified mirrors automatically.

Check the returned Skill version and actual installed capabilities. If Agensi still serves a version below 2.2, identify it as the older workflow and use an available verified v2.2 source kit instead. Publication and live-test status are separate; see the repository's validation report before claiming a particular client or marketplace version has passed.
