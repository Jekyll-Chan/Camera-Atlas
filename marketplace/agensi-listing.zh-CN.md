# Camera Atlas — 免费版 v2

价格：Free（免费）。Skill 版本：2.0.0；使用固定、已测试的 Python 引擎 0.1.0。

保留原照片的构图和色彩，为旅行摄影添加有真实来源的克制地图注解，输出成品、透明地图图层和数据来源。准备一张照片和拍摄地点即可，精确机位 GPS 不是必填项。

先检查当前 Agent 的能力：具备 Python 3.11+、文件读写和安装条件时，建立独立环境并实际制图；无法执行时，交付明确标注的编辑设计方案。没有视觉工具就不声称已经看过照片。可先用公开 NASA/Natural Earth 样片试用。

所需能力：授权的照片/输出文件；实际制图需要 Python 3.11+ 与独立环境安装权限；首次准备和线上地理查询需要网络；视觉构图检查需要图像理解工具，否则由用户复核；外部事实核实需要浏览能力或可信来源。

提供中英双语新手说明。核心/样片流程不要求付费 Agensi 图片工具、生成式照片重绘或地名 API Key。AI 账户、网络和计算资源可能另有费用。本技能不包含托管云端制图。

限制：负空间分析是纹理启发式；未实现复杂 OSM 关系组装、自动 DEM 下载、高位深合成及所有 Agent 的通用实测兼容。缺少可靠地理数据时给出干净照片或明确说明的方案；文字插值需审阅掩膜，不能恢复真实被遮挡细节。

源码与完整文档：https://github.com/Jekyll-Chan/Camera-Atlas 。代码 MIT；地图数据、照片各保留自己的许可。私人原图/GPS 不用于公开商品示例。
