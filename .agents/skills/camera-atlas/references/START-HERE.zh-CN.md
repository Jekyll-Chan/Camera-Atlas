# Camera Atlas 免费版 v2：第一次怎么用

你只需要准备一张照片和一个拍摄地点。其余环境检查、地图数据和文件输出交给 Agent 处理。

## 在 Agensi 使用

1. 注册/登录 Agensi，按它的连接说明，把你正在使用的 Agent 连接到 Agensi：https://www.agensi.io/docs/mcp-setup 。连接时可能需要你亲自登录和确认。支持情况取决于你的应用、账户和实际工具权限。
2. 正式上架后，在 Agensi 搜索 **Camera Atlas**，确认作者/仓库指向 **Jekyll-Chan/Camera-Atlas**、价格为 **Free**。本文件随 v2 适配包提供，不表示它已经被平台审核或上架；搜不到时可用下方 GitHub 路径。
3. 回到已连接的 Agent 聊天，发送照片并复制这句话：

> 使用免费的 Camera Atlas 帮我处理这张旅行照片，地点是【填入拍摄地点】。请先检查你能否实际生成图片；如果需要，请在本次工作区准备独立运行环境，保持原图构图和色彩，添加有真实来源的细地图。完成后给我成品和透明图层。如果这里不能生成图片，请明确告诉我，并给我可执行的设计方案。

不用懂 Python、地图 API 或 GeoJSON；也不必提供精确 GPS。只知道“赛里木湖，新疆，中国”也可以，Agent 应将它当作地区，不能假装知道你的精确机位。同名地点可能需要补充国家/省份。

## 不想先用自己的照片？

发送：

> 使用 Camera Atlas 的公开样片演示，检查环境并准备必要依赖，让我先看看成品和透明图层。暂时不用我的私人照片。

公开示例是 NASA 航空/航天摄影与真实 Natural Earth 湖岸，不是地面旅行样片。演示不上传你的照片，也不要求地名服务 API Key。

## 会有哪两种结果？

- **能实际制作**：Agent 具备 Python 3.11+、读写文件和必要网络/数据条件，会输出图片。第一次可能下载约 61 MB 的公开引擎源码及额外依赖，之后可复用独立环境。成功制作后先打开 `final.png`；`map_overlay.png` 是可导入 Photoshop 等软件的透明图层；`provenance.json` 记录来源。
- **只能做方案**：当前 Agent 没有可用的代码执行环境、禁止安装依赖，或数据无法核实。它会给你“设计方案，尚未出图”，说明位置、地图样式、应保护的主体和下一步。方案不是成品。

图片能被 Python 读取，不代表 Agent 能看懂图片。若 Agent 没有视觉查看工具，它应说明只做了自动检查，需要你检查构图。地图数据不足时，也可能返回没有地图的干净照片；它应说明原因，不能声称已经成功加图。

## 常用修改，直接这样说

- “地图再淡一点，移到右上角。”
- “不要地名，保留必要的数据署名。”
- “不要遮挡人物、山峰和船只。”
- “这次只做方案，先别安装东西。”
- “保留所有独立图层，方便以后修改。”

## 没用 Agensi，也能用

打开 https://github.com/Jekyll-Chan/Camera-Atlas ，把仓库交给能运行 Python 的 Agent，然后说：

> 请读取这个仓库的 Camera Atlas Skill v2，帮我检查并准备独立环境，再用公开样片演示。我不熟悉命令行，请你完成技术步骤。

也可直接上传 `.agents/skills/camera-atlas/` 中的 Skill 和相关文本资源，具体取决于你使用的 Agent。不要把整个 61 MB 项目 ZIP 当作 Agensi 技能包上传；它有单独的轻量适配包。

## 费用与隐私

Camera Atlas 这个适配技能免费，核心渲染不调用付费生成图片服务。你的 Agent/AI 账户本身可能收费，网络和计算资源也由所在环境提供；免费技能不等于所有服务免费。本版不会自动购买 Agensi 工具、开通订阅或申请 API Key。

原图只交给你授权的 Agent 环境处理。使用线上地图时会向地图提供商查询地点/范围；不要输入保密地点。切换 Agent 时，照片不会由本技能自动传送。不要在公开 GitHub 或商品示例中上传私人原图/GPS。

## 如果卡住

- 搜不到技能：可能尚未上架，使用 GitHub 方式；不要购买同名的未知作者版本。
- 连接失败：先用 Agensi 官方连接说明完成登录。当前平台说明一次只保留一个 Agent 连接，换应用可能需要重新连接。
- 提示缺少 Python/网络/安装权限：请它切换为设计方案，或换到具备这些能力的环境。
- 地图没出现：请它解释 `provenance.json` 中的警告。不要让它为了好看编造地图。
- 找不到成品：请它给出实际存在的 `final.png` 文件/下载链接。尚未出图时不要接受“已经完成”的说法。
